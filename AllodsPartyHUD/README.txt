AllodsPartyHUD v1.6 — обмен настройками через текстовый код APH1

Открой «ГРУППА» → вкладка «ОБМЕН».
ЭКСПОРТ: выбери ВСЁ, БАФЫ / ДЕБАФЫ или ОТКАТЫ, нажми «СФОРМИРОВАТЬ КОД».
Щёлкни по полю с кодом, нажми Ctrl+A и Ctrl+C для копирования.
ИМПОРТ: вставь код Ctrl+V в нижнее поле, нажми «ПРОВЕРИТЬ КОД»,
выбери «ОБЪЕДИНИТЬ» или «ЗАМЕНИТЬ», затем «ПРИМЕНИТЬ ИМПОРТ».

«ОБЪЕДИНИТЬ»: добавить отсутствующие именованные эффекты/КД; существующие
настройки (размеры, цвета, старые записи) не менять.
«ЗАМЕНИТЬ»: перезаписать только поля, присутствующие в полученном коде.
Импорт выполняется после отдельной проверки кода; код имеет контрольную сумму.

Формат APH1 собственный и НЕ совпадает с кодами ADSC / Universe.
Файлы конфигураций других аддонов можно будет обработать отдельно позже.
Положение HUD/кнопки DnD не входит в экспорт, чтобы не переносить чужие координаты.
Вставленный код не исполняется как Lua.
Сохранение по-прежнему штатное — userMods.Get/SetGlobalConfigSection.
В игровом клиенте новый интерфейс ещё требует проверки.
